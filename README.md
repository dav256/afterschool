# Afterschool

Dark fern.best-style theme. Local games only.

## Included local games
- **Retro Bowl** — full game files under `games/retro-bowl/`
- **2048** — full local code under `games/2048/`

## Other games in the list
They show up with icons. To make them playable, drop the game folder from GitHub into `games/<name>/` so the path matches (e.g. `games/slope/index.html`), or use Admin → Add game.

## Admin
Password: `afterschool`  
Add / remove / reorder games, change accent color and site name.

## Run
Open `index.html` or `npx serve .`
